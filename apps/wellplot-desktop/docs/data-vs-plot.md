# 数据与绘图分离（模型 A）

**Status:** product decision (user-confirmed)

## 决策

| 层 | 归属 | 内容 |
|----|------|------|
| **数据** | **井（Well）** | 导入 LAS 等到 `wells/<id>/`；内容树 = 导入源 → **井道叶子**（全部可用曲线） |
| **绘图** | **井图（Plot）** | `plots/<id>.json` 绑定 `well_ids` + **display_set（勾选叶子）** + 图版样式；**不**内嵌样点 |

数据 **导入到井**，不是导入进图件文件。井图通过勾选选用该井树形表中的井道。

同一井可开多张井图：数据一份，各图各自 display_set / 图版。

## 树形表（左栏单树，无双 Tab，无工区根节点）

```
数据
└─ A2.Las（井A） → 「单井分析图」   ← 以数据为单位；名后标注引用图
     ├─ GR                          ← 井道清单（不写引用）
     ├─ AT10
     └─ …
图件
└─ 单井分析图 [单井·多图道]
     ├─ ☑ GR                        ← 图 → 井道
     ├─ ☑ RT
     └─ …
```

- 顶层仅 **数据** 与 **图件** 两项（无「工区」产品概念节点）  
- **数据区**：以**数据单元**（导入源）为节点；子节点是井道清单；**无勾选**  
- 数据已被图件引用时，只在**数据名后**标 `→ 「图名」`，不在具体井道名上标  
- **图件区**：树形始终 **图 → 井道**（多井时 **图 → 井 → 井道**）；勾选控制本图 Display Set  
- 双击数据井道 = 加入当前打开的单井图（写 binding，不复制样点）  
- 冷启动直接进入主界面（自动打开最近/默认存储）  
- 深度尺不是树节点；图版只负责样式/布局（双层合成）  

## 持久化

- 曲线样点：井数据文件  
- `display_set`：单井图 schema v6 字段（leaf id 列表）  
- `data_bindings`（schema v7）：每条「图↔井道」链接有 **`binding_id`** + `plot_id` + `well_id` + `leaf_id`  
- 未打开图件时勾选仅会话缓存（`well:<id>`）  

## 默认显示井道

- 图件 **尚无** 已保存 `display_set` 时：按图版槽位 + 常用井道优先级自动挑选一批默认井道，**最多 10 条**  
- 用户已设置 / 拖放 / 右键加入后的 `display_set` **原样采用**（可超过 10，不截断）

## 从数据区到图区

- **拖放**：将数据单元或井道拖到图件节点（图 / 图下井道）  
- **右键菜单**：数据侧「加入当前井图 / 加入到图件 / 新建图并加入」；图件侧「打开 / 导出 / 从本图移除」  
- 双击树中井道叶子，或 **图件 → 将选中井道加入当前井图**  
- 只增加绑定标识，**不复制样点**  
- LAS 仍 **导入到井**（文件菜单：导入 LAS 到井…）

## 图定义 XML / Excel

| 动作 | 菜单 |
|------|------|
| 导出 | 图件 → 导出井图定义 XML / Excel |
| 导入 | 文件 → 导入井图定义 XML / Excel |

导入的是 **图的结构与绑定**（well_id、leaf_id、binding_id、图版…），要求井数据已在工区中。
