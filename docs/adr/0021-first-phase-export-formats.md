# 首期图形导出支持 PDF、SVG、PNG 与 TIFF

PDF/SVG 以物理页面、指定测井比例尺和深度分页输出，曲线使用面向目标页面精度的包络矢量，文字优先保留为可搜索文本并嵌入字体子集，图纹、区间、网格和曲线保持矢量，源栅格图像保持栅格。纯矢量与混合高保真模式必须由用户显式选择，不得静默降级；PNG/TIFF 用于高分辨率栅格输出，CGM 延后为可能的企业交换插件。

> **B1 指针**：**CGM** 的选型与后端边界见 **ADR 0054**（独立 Export Backend，实现前不得宣称支持）。引擎 PDF **可搜索**可选路径见 **ADR 0053**（相对 ADR 0047）。首期（B0）交付物仍以本 ADR 的 PDF/SVG/PNG/TIFF 为主门禁。
